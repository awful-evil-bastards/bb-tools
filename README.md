# Biceps & Brimstone — The App Suite

Three installable web apps (PWAs), one per folder:

- **bb-charsheet-app/** — the Character Sheet
- **bb-forge-app/** — the Character Forge (guided creation)
- **bb-gm-engine-app/** — the Brimstone GM Engine (fights, initiative, adventures, names)

Each folder is self-contained: host it anywhere static (GitHub Pages, itch.io), open the URL, and Add to Home Screen. Same packaging as the Dragonbane app.
